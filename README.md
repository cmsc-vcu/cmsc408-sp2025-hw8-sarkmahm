# cmsc408-sp2025-hw8

Homework 8 - World Bank Indicator Analysis


This project explores SQL skills by analyzing real data from the World Bank. The goal is to answer questions about countries, regions, and income groups using SQL queries.

## What You Need

- Python 3
- Jupyter Notebook
- SQLAlchemy, Pandas
- Quarto (for report generation)

Install Python packages:

```bash
pip install pandas sqlalchemy jupyter
```

## Files and Folders
- report.qmd – Main notebook with all tasks

- report.html – Final generated report

- helpers.py – Helper functions for SQL connection

- .quarto.yml – Quarto config

- source-data/ – Raw data if provided

Running :

```bash
quarto render report.qmd
```
